# X-OS

X-OS is a SillyTavern phone simulator extension for immersive, in-chat virtual social and livestream interactions.

## Package

The initial release package and installation notes will be published here. The extension is designed for local simulation; it does not connect to real messaging, social-media, or payment services.

## Installation

1. Download the extension package from the repository release or package directory.
2. Extract `X-Phone-Simulator-Extension` into `SillyTavern/data/default-user/extensions/`.
3. Restart or refresh SillyTavern and enable the extension.

See the extension README for details and limitations.
